⚡ LiteBinds — Управление горячими клавишами и способностями
LiteBinds — это современный, высокопроизводительный плагин для серверов Minecraft (Paper 1.16.5+), который предоставляет игрокам удобный графический интерфейс (GUI) для настройки и привязки кастомных игровых механик, способностей и предметов к стандартным действиям персонажа.

🎮 Ключевые возможности для игроков
Интуитивный GUI (/binds): Наглядное меню для управления привязками в несколько кликов с динамическим отображением статусов.

Гибкие триггеры активации: Возможность привязать способности к привычным действиям:

🟢 Выбросить предмет ([Q])

🟡 Вторая рука ([F])

🔵 Использовать / ПКМ ([ПКМ])

Разнообразие кастомных эффектов: Поддержка множества уникальных модулей (снежки, ловушки, станы, взрывные устройства, виртуальные рюкзаки и др.).

Полный контроль: Возможность быстрого сброса или переключения активных биндов через интерактивные элементы меню.

⚙️ Технические особенности (Under the Hood)
Асинхронная архитектура и производительность: Все операции с базой данных кэшируются через потокобезопасные структуры (ConcurrentHashMap), что полностью исключает фризы и блокировку основного потока сервера (Main Thread) во время игровых событий.

Надежное хранение данных (HikariCP): Поддержка высокопроизводительного пула соединений с возможностью работы как на локальном SQLite, так и на масштабируемых базах данных MySQL.

Современный визуальный стиль: Поддержка градиентов и форматирования текста с помощью экосистемы MiniMessage и Adventure API.

Enterprise-стандарты разработки: Строгое разделение логики, отсутствие утечек памяти и полная оптимизация под высоконагруженные серверные экосистемы.
